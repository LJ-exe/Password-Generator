# 🔐 Python Password Generator

A simple and beginner-friendly **Python password generator** that creates random passwords based on the user's preferred character type.

## ✨ Features

* Generate passwords using **letters only**
* Generate passwords using **numbers only**
* Generate **strong mixed passwords** using letters, numbers, and special characters
* Choose the desired password length
* Input validation for invalid options
* Simple command-line interface

## 🛠️ Technologies

* **Python 3**
* `string` module
* `sys` module
* `random` module

## 🚀 How to Use

1. Run the Python script.
2. Enter the desired password length.
3. Choose the password type:

   * `1` → Letters
   * `2` → Numbers
   * `3` → Mixed characters
4. The program generates your password automatically.

## 📌 Example

```text
Enter password length: 12

Choose password type:
1 - Letters
2 - Numbers
3 - Mixed

Your password: aKpTzQwLxR8!
```
